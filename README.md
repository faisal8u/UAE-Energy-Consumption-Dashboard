# UAE Energy Consumption & Demand Dashboard 2023

## Project Overview
An interactive Excel dashboard analyzing UAE electricity 
consumption and demand patterns for 2023 across Dubai, 
Abu Dhabi and Sharjah.

## Business Questions Answered
- How did total consumption trend month by month?
- Which region generated and consumed the most?
- What was the energy mix — Solar vs Gas vs Nuclear?
- When was peak demand highest?

## Key Findings
- Total Generation: 2,114,000 MWh
- Total Consumption: 2,071,900 MWh
- Peak Demand: 1,380 MW (July-August summer peak)
- Avg Capacity Factor: 58.05%
- Total CO2 Emissions: 473,210 Tonnes
- Abu Dhabi led generation at 956,000 MWh
- Gas dominated energy mix at 43% of total generation
- Nuclear (Barakah) contributed 32% of total generation
- Peak demand driven by UAE summer heat and AC usage

## Dashboard Features
- 5 KPI cards showing headline metrics
- Monthly consumption trend line chart
- Regional generation vs consumption column chart
- Energy mix donut chart with percentages
- Monthly peak demand line chart
- Clean professional layout

## Data Structure
| Column | Description |
|--------|-------------|
| Month | Jan-23 to Dec-23 |
| Region | Dubai, Abu Dhabi, Sharjah |
| Source | Solar, Gas, Nuclear |
| Generation_MWh | Electricity produced |
| Consumption_MWh | Electricity consumed |
| Peak_Demand_MW | Highest demand recorded |
| Capacity_Factor_% | Plant performance |
| Cost_per_MWh | Production cost |
| CO2_Tonnes | Carbon emissions |
| Line_Loss_MWh | Transmission loss |
| Line_Loss_% | Loss percentage |
